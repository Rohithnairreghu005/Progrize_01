# Progrize

A React landing page for a job platform promising a reply within ten days, useful rejection feedback and upfront pay. The current visual authority is Figma frame 50:114 in the Jobhunter file: a Manrope light theme with lime accents, illustrations and green line drawings.

The existing GSAP/Lenis animation system and job-search interactions are preserved, with the application assembly animation adapted to the new character illustration. Figma supplies visual design; the reference website supplies the established motion language.

Account, application and newsletter flows remain local demonstrations. No backend, authentication, email delivery or persistent storage is connected. Job and employer statistics are illustrative.
